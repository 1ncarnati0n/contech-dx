## 1. 프로젝트 개요

### 1.1 프로젝트명

**CastPlan** - 웹 기반 기초 타설 계획 및 장비 동선 관리 도구

### 1.2 통합 정보

> **통합 대상**: ConTech-DX 프로젝트
> **통합 방식**: 기존 "타설구간 개략검토" 페이지 확장
> **모드 전환**: Simple (기존 계산) ↔ Visual (캔버스 기능)

CastPlan은 독립 프로젝트가 아닌 **ConTech-DX 프로젝트의 일부**로 구현됩니다. 기존 `PouringSectionReviewPage.tsx`를 확장하여 Simple/Visual 두 가지 모드를 제공합니다.

### 1.2 프로젝트 배경

지하층 기초 공사 시 타설 계획 수립은 공정 관리의 핵심입니다. 현재 실무에서는 다음과 같은 문제점이 있습니다:



| 문제 | 현황 | 영향 |
|------|------|------|
| **수작업 계획** | CAD에서 구역 나누고 엑셀로 물량 계산 | 비효율, 오류 발생 |
| **동선 검토 어려움** | 2D 도면으로 펌프카 접근성 판단 | 현장 충돌, 재계획 |
| **협업 단절** | 도면-공정표-물량표 별도 관리 | 정보 불일치 |
| **변경 대응 지연** | 계획 변경 시 전체 재작업 | 공기 지연 |
| **현장 공유 어려움** | 출력물 기반 소통 | 최신 정보 미반영 |


### 1.3 타설 계획 수립 시 고려 사항

1. 대지를 타설 가능한 블록(Zone)으로 분할
2. 레미콘 펌프카 배치 위치 결정
3. 펌프카 붐 도달 범위 확인
4. 게이트별 장비 진입 동선 계획
5. 타설 순서 및 일정 수립
6. 블록별 콘크리트 물량 산출
7. 콜드 조인트 방지를 위한 연속 타설 검토

### 1.4 솔루션

DXF 도면 위에 타설 구역을 분할하고, 게이트/장비 배치를 시뮬레이션하여 최적의 타설 계획을 수립하는 웹 도구를 개발합니다.

### 1.5 핵심 가치

> **"타설 구역 분할부터 물량 산출, 장비 배치까지 한 화면에서"**

### 1.6 프로젝트 범위

#### In Scope (포함)

- 지하층 기초 타설 계획 (MAT 기초, 독립기초, 줄기초)
- 골조 슬래브 타설 계획
- 레미콘 펌프카 배치 및 도달 범위 시뮬레이션
- 게이트 및 장비 진입 동선 계획
- 타설 구역별 물량 산출

#### Out of Scope (제외)

- 구조 설계/검토 - 전문 구조 소프트웨어 영역
- 레미콘 배차 관리 - 별도 시스템
- 실시간 타설 모니터링 - IoT 연동 필요
- BIM/IFC 연동 - v2.0 검토

## 2. 타겟 사용자

### 2.1 주요 사용자 (Primary)

| 사용자 | 역할 | 핵심 니즈 | 사용 빈도 |
|--------|------|----------|----------|
| **현장 공무팀** | 타설 계획 수립 | 구역 분할, 물량 산출, 일정 계획 | 매일 |
| **현장 소장** | 계획 검토/승인 | 전체 계획 확인, 리스크 검토 | 주 2-3회 |
| **펌프카 기사** | 배치 위치 확인 | 정확한 배치 위치, 진입 동선 | 타설일 |

### 2.2 보조 사용자 (Secondary)

| 사용자 | 역할 | 핵심 니즈 |
|--------|------|----------|
| 레미콘 업체 | 배차 계획 | 타설 일정, 물량 정보 |
| 안전 관리자 | 동선 안전 검토 | 장비 이동 경로, 위험 구역 |
| 본사 PM | 공정 모니터링 | 타설 진행 현황 |

### 2.3 페르소나

#### 페르소나 A: 박대리 (건설사 현장 공무팀, 5년차)

현재 지하 3층 규모 오피스 빌딩 현장에서 MAT 기초 타설 계획을 담당하고 있습니다. AutoCAD와 Excel을 사용하여 계획을 수립합니다.

**현재 워크플로우:**
- 1일차: CAD에서 타설 구역 나누기 (반나절)
- 2일차: 각 구역 면적 산출 → 엑셀 입력, 콘크리트 물량 계산
- 3일차: 펌프카 배치 검토 (CAD에 원 그려가며 붐 도달 범위 확인)
- 4일차: 타설 순서 결정, 일정표 작성
- 5일차: 현장소장 검토 → 수정 → 재검토...

**Pain Points:**
- *"CAD에서 구역 나누고, 엑셀에서 물량 계산하고... 왔다갔다가 너무 번거로워요"*
- *"펌프카 붐 길이가 52m인데, 실제로 닿는지 CAD로 확인하기 어려워요"*
- *"계획 변경되면 처음부터 다시... 야근 확정이에요"*

**기대 효과:**
- 타설 계획 수립 시간 70% 단축
- 실시간 물량 계산으로 오류 제거
- 펌프카 도달 범위 시각적 확인

## 3. 도메인 개념 정의

### 3.1 핵심 용어

| 용어 | 정의 | 예시 |
|------|------|------|
| **대지 (Site)** | 전체 공사 영역 | DXF로 불러온 지하층 바닥 전체 |
| **블록 (Block/Zone)** | 한 번에 타설하는 단위 구역 | MAT 기초를 4개 블록으로 분할 |
| **게이트 (Gate)** | 장비 진입 출입구 | 공사장 정문, 후문, 가설 게이트 |
| **장비 (Equipment)** | 타설에 사용되는 기계 | 펌프카, 레미콘 트럭 |
| **배치점 (Placement)** | 장비가 설치되는 위치 | 펌프카 고정 위치 |
| **도달 범위 (Reach)** | 장비가 커버하는 영역 | 펌프카 붐 반경 52m |
| **동선 (Route)** | 장비 이동 경로 | 게이트 → 배치점 → 게이트 |
| **타설 순서 (Sequence)** | 블록별 시공 순서 | 1→2→3→4 순차 타설 |

### 3.2 펌프카 타입별 사양

| 타입 | 붐 길이 | 수평도달 | 수직도달 | 차량폭 | 아웃트리거 |
|------|---------|---------|---------|--------|-----------|
| 36M 펌프카 | 36m | 32m | 36m | 2.5m | 8.2m |
| 42M 펌프카 | 42m | 38m | 42m | 2.5m | 8.6m |
| **52M 펌프카** | **52m** | **48m** | **52m** | **2.5m** | **9.4m** |
| 56M 펌프카 | 56m | 52m | 56m | 2.8m | 10.2m |
| 63M 펌프카 | 63m | 59m | 63m | 2.8m | 11.0m |

> **※ 52M 펌프카가 가장 일반적으로 사용됩니다.**

### 3.3 타설 계획 워크플로우

| 단계 | 작업 | 입력 | 출력 | 도구 |
|------|------|------|------|------|
| 1 | 도면 로드 | DXF 파일 | 캔버스에 도면 표시 | DXF 파서 |
| 2 | 구역 분할 | 대지 경계 | 타설 블록들 | 분할선 도구 |
| 3 | 게이트 설정 | 진입구 위치 | 게이트 목록 | 게이트 도구 |
| 4 | 장비 배치 | 펌프카 타입/위치 | 도달 범위 표시 | 펌프카 도구 |
| 5 | 동선 계획 | 이동 경로 | 동선, 간섭 검토 | 동선 도구 |
| 6 | 타설 순서 | 순서 지정 | 시뮬레이션 | 순서 설정 UI |
| 7 | 물량 산출 | 두께, 할증률 | 물량표 | 자동 계산 |
| 8 | 출력/공유 | - | Excel, PDF | 내보내기 |

### 4.2 상세 기능 명세

#### F03: 블록 분할

대지 경계 내부를 분할선으로 나누어 독립된 타설 블록을 생성합니다.

**분할 방식:**

| 방식 | 설명 | 사용 상황 |
|------|------|----------|
| 직선 분할 | 두 점을 연결하는 직선 | 일반적인 구역 분할 |
| 폴리라인 분할 | 여러 점을 연결 | 불규칙한 분할 |
| 그리드 분할 | 격자 형태 자동 분할 | 균등 분할 시 |
| DXF 스냅 분할 | 기존 도면선 따라 분할 | 기둥/벽 라인 기준 |

**상호작용:**
1. [분할 도구] 선택
2. 분할할 블록 선택 (또는 전체 대지)
3. 분할선 시작점 클릭 (경계에 스냅)
4. 분할선 끝점 클릭 (경계에 스냅)
5. 자동으로 2개 블록 생성
6. 각 블록에 이름 자동 부여 (A-1, A-2 등)

#### F07-F08: 펌프카 배치 및 도달 범위

펌프카 배치 위치를 지정하고, 붐이 도달하는 범위를 시각화합니다.

**도달 범위 시각화:**
- **최대 도달 범위**: 붐 길이 기준 원형 영역
- **권장 작업 반경**: 5m 여유를 둔 안전 영역
- **아웃트리거 영역**: 장비 설치에 필요한 공간
- **미도달 영역**: 빨간색으로 경고 표시

**커버리지 분석:**
- 각 블록별 도달 가능 여부 표시 (✓/✗)
- 최대 거리 및 여유 거리 계산
- 미도달 블록에 대한 권장 조치 안내
- 펌프카 위치 자동 최적화 기능

#### F09: 타설 순서 설정

블록별 타설 순서를 지정하고, 콜드 조인트 방지를 위한 검토를 수행합니다.

**타설 순서 규칙:**
- 콘크리트 타설 간격: 동절기 2시간, 하절기 1.5시간 이내
- 인접 블록 연속 타설 권장
- 시공 조인트 위치 고려
- 구조적 연속성 확보

**상호작용:**
- 블록 클릭 → 순서 번호 자동 증가
- 드래그로 순서 변경
- 시뮬레이션 재생으로 순서 검증

### 5.2 블록 속성 패널

블록 선택 시 오른쪽 또는 사이드바에 속성 패널이 표시됩니다.

| 항목 | 입력 형식 | 설명 |
|------|----------|------|
| 이름 | 텍스트 입력 | Block A, Zone 1 등 |
| 두께 | 숫자 입력 (m) | 콘크리트 타설 두께 |
| 강도 | 드롭다운 선택 | 25-24-15 등 |
| 할증률 | 숫자 입력 (%) | 기본 5% |
| 타설 순서 | 드롭다운 선택 | 1, 2, 3... |
| 예정일 | 날짜 선택 | 타설 예정일 |
| 색상 | 컬러 피커 | 블록 표시 색상 |

**자동 계산 항목 (읽기 전용):**
- 면적: ㎡ 단위
- 둘레: m 단위
- 순물량: 면적 × 두께 (㎥)
- 발주량: 순물량 × (1 + 할증률) (㎥)

| 3 | Gate Layer | 게이트 위치 및 방향 |
| 4 | Equipment Layer | 펌프카 배치 |

| 6 | Route Layer | 장비 동선 (화살표) |
| 7 (최상위) | UI Layer | 스냅 인디케이터, 가이드선 |

## 13. 부록: 콘크리트 강도 표기법

콘크리트 강도는 **"25-24-15"**와 같이 3개의 숫자로 표기합니다.

| 위치 | 의미 | 설명 |
|------|------|------|
| 첫 번째 (25) | 설계기준강도 | 28일 압축강도 (MPa) |
| 두 번째 (24) | 슬럼프 | 콘크리트 유동성 (cm) |
| 세 번째 (15) | 굵은골재 최대치수 | 자갈의 최대 크기 (mm) |

**일반적인 강도 예시:**
- **기초**: 24-24-25, 25-24-25
- **기둥/보**: 27-18-25, 30-18-25
- **슬래브**: 24-15-25, 27-15-25
