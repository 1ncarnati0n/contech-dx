| 유로폼(지하 벽체 – 외곽/내력벽) | 형틀㎡, 콘크리트㎥ | h_ug, t_slab_ug, k_beam_ug | ① A_s = 콘크리트㎥ / t_slab_ug ② A_sf = A_s × k_beam_ug ③ 벽체유로폼㎡ = MAX(0, 형틀㎡ − A_sf) ④ 벽체연장 L = 벽체유로폼㎡ / h_ug | Front = CEILING(L / L_front) | 지하벽은 cap이 “전선” 지배. h_ug를 잘못 주면 Front가 크게 흔들림 → 지하층고만큼은 입력 추천 |

| 기초 철근(매트/독립기초) | 콘크리트㎥(기초), 철근ton | t_mat(기초두께), A_zone_slab=200㎡ | 기초면적 A_f = 기초콘크리트㎥ / t_mat | Zone_found = CEILING(A_f / 200) | 기초는 “자유구획”이라 Zone 기반이 맞음. 두께(t_mat)만 알면 면적이 안정적으로 나옴 |
